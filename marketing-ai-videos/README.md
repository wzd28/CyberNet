# marketing-ai-videos

Workspace for researching, planning and producing AI-assisted marketing videos.

| Path | What it is |
|---|---|
| `TASTE.md` | Standing creative preferences. **Read first, every project.** Updated after every round of feedback. |
| `research/GRANDMASTER.md` | **The operating manual.** Method, routing to skills, hooks, motion, sound, distribution, pre-flight checklist. **Read second, every task.** |
| `skills-library/` | 123 third-party MIT/Apache skill playbooks (Ootto, Corey Haines, HyperFrames), indexed in `INDEX.md`. Reference only. |
| `research/SUMMARY.md` | Condensed playbook, per-platform checklists, pre-publish QA. **Read second.** |
| `research/*.md` | One file per platform plus AI tools, psychology and case studies, all with cited sources. |
| `templates/video-brief.md` | Reusable brief: goal → audience → platform → hook → concept → script → shots → prompts → VO → captions → music → CTA. |
| `projects/<name>/` | One folder per client or project. See `projects/README.md`. |

## Where this lives
It was asked for on the desktop, but this was built in a cloud container that has no desktop and is deleted after the session. So it's committed to the `claude/vibrant-cerf-17gupi` branch of `wzd28/CyberNet` instead. To move it to your desktop:

```bash
git clone -b claude/vibrant-cerf-17gupi https://github.com/wzd28/CyberNet.git /tmp/cn && cp -r /tmp/cn/marketing-ai-videos ~/Desktop/
```

**`wzd28/CyberNet` is a public repository.** Research and templates are fine there. Client source files (logos, images, briefs, unreleased work) are not. Keep `projects/<client>/source/` out of this repo: move the folder to a private repo or your machine before adding client material. `projects/*/source/` is gitignored as a safety net.

## Research freshness
Research was gathered in November 2026. Platform algorithms and AI-tool pricing change monthly, so re-verify any number before you put it in a client deck.
